
# BodyWise — BMI Calculator

BodyWise is a Python-based BMI Calculator with a modern graphical user interface built using CustomTkinter.

## Features
- Calculate BMI using weight and height
- Circular BMI gauge
- Adult BMI category interpretation
- Input validation and error handling
- Age-aware messaging for children and teenagers
- Offline functionality

## Technologies Used
- Python
- CustomTkinter
- Tkinter Canvas



## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/misbah-javed/Bodywise---bmi-calculator.git
   ```

2. Open the project folder:

   ```bash
   cd Bodywise---bmi-calculator
   ```

3. Install the required dependency:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## Important Note
BMI is a screening measure, not a medical diagnosis. Adult BMI categories are used for adults aged 20 and above. Children and teenagers require age- and sex-specific BMI percentile assessment, which this version does not calculate.
